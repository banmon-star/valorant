# 锦鲤科技 · 无畏契约玩家福利

这是独立的静态抽奖页面，包含首页和 `images/registration-qr.png` 活动二维码。

## 发布成另一个 GitHub Pages 网站

1. 在 GitHub 新建一个单独的公开仓库，例如 `valorant-draw`。
2. 将本目录中的 `index.html`、`images/` 和 `README.md` 上传到新仓库根目录。
3. 在新仓库打开 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**，Branch 选 `main`，目录选 `/(root)`，保存。
5. 等 GitHub 部署完成，网站网址通常为 `https://banmon-star.github.io/valorant-draw/`。

本页面的参与状态使用独立浏览器存储键，和原有数码奖品抽奖页分开。页面概率未展示；参与记录和人数显示均为静态演示行为。
